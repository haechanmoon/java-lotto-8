# java-lotto-precourse
# [프리코스 3주차] 로또

## 기능 요구 사항
### 간단한 로또 발매기를 구현한다.

- 로또 번호의 숫자 범위는 1~45까지이다.
- 1개의 로또를 발행할 때 중복되지 않는 6개의 숫자를 뽑는다.
- 당첨 번호 추첨 시 중복되지 않는 숫자 6개와 보너스 번호 1개를 뽑는다.
- 당첨은 1등부터 5등까지 있다. 당첨 기준과 금액은 아래와 같다.
  - 1등: 6개 번호 일치 / 2,000,000,000원
  - 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
  - 3등: 5개 번호 일치 / 1,500,000원
  - 4등: 4개 번호 일치 / 50,000원
  - 5등: 3개 번호 일치 / 5,000원 
- 로또 구입 금액을 입력하면 구입 금액에 해당하는 만큼 로또를 발행해야 한다.
- 로또 1장의 가격은 1,000원이다.
- 당첨 번호와 보너스 번호를 입력받는다.
- 사용자가 구매한 로또 번호와 당첨 번호를 비교하여 당첨 내역 및 수익률을 출력하고 로또 게임을 종료한다.
- 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시키고, "[ERROR]"로 시작하는 에러 메시지를 출력 후 그 부분부터 입력을 다시 받는다.
  - Exception이 아닌 IllegalArgumentException, IllegalStateException 등과 같은 명확한 유형을 처리한다.

## 구현할 기능 목록
- [ ] 로또 구입 금액 입력받기
- [ ] 구입 금액에 따른 로또 구매 개수 계산 및 출력
- [ ] 구매한 로또 번호 목록(6자리, 오름차순)을 개수만큼 생성 및 출력
- [ ] 당첨 번호 6개 입력받기
- [ ] 보너스 번호 1개 입력받기
- [ ] (Enum 활용) 당첨 기준(1~5등)과 상금을 관리
- [ ] 구매한 로또와 당첨 번호를 비교하여, 등수별 당첨 내역 집계 및 출력
- [ ] 총 수익률 계산(소수점 둘째 자리 반올림) 및 출력

## 예외 처리 (모든 예외 발생 시 [ERROR] 출력 후, 해당 부분부터 다시 입력받기)
- [ ] 구입 금액이 1,000원 단위가 아닐 때
- [ ] 구입 금액이 0 이하의 정수일 때
- [ ] 구입 금액이 숫자가 아닐 때
- [ ] 당첨 번호가 6개가 아닐 때
- [ ] 당첨 번호에 1~45 범위를 벗어난 숫자가 있을 때
- [ ] 당첨 번호에 중복된 숫자가 있을 때
- [ ] 보너스 번호가 1~45 범위를 벗어난 숫자가 있을 때
- [ ] 보너스 번호가 당첨 번호와 중복될 때

## 테스트 목록
- [ ] (Validator) 구입 금액이 1,000원 단위가 아닐 때 (`"1500"`) 예외 발생
- [ ] (Validator) 구입 금액이 0일 때 (`"0"`) 예외 발생
- [ ] (Validator) 구입 금액이 숫자가 아닐 때 (`"abc"`) 예외 발생
- [ ] (Lotto) 로또 당첨 번호가 6개가 아닐 때 (`"1,2,3"`) 예외 발생
- [ ] (Validator) 당첨 번호에 중복이 있을 때 (`"1,1,2,3,4,5"`) 예외 발생
- [ ] (Validator) 당첨 번호에 범위 밖 숫자가 있을 때 (`"1,2,3,4,5,46"`) 예외 발생
- [ ] (Validator) 보너스 번호가 범위 밖일 때 (`"46"`) 예외 발생
- [ ] (Validator) 보너스 번호가 당첨 번호와 중복될 때 (`"1,2,3,4,5,6"`, `"6"`) 예외 발생
